## California staff workspace batch (not yet deployed)

Added a separate California staff workspace on the existing Civil board, assignments,
calendar, party search and reports routes. It uses standard agency roles and shared
`civil.papers` records, rather than the Platform Admin-only summons demonstration table.
Dashboard intake and My Work case links route to the California workspace.

Supported case-management paths: summons, small claims, subpoena, restraining order,
earnings withholding, execution, bank levy, possession, personal property levy,
real property levy and sheriff sale. These are workflow scaffolds with manually
reviewed packet requirements. They do not implement every statute-specific notice,
exemption deadline, service method restriction, sale distribution or generated court
form for each case type. Uploaded completed returns require independent review.
No legal deadline or fee is calculated from Arizona defaults.

Server safeguards: tenant/agency membership and licensing; own-assignment visibility;
role abilities; version checks under row lock; audit and case updates in one
transaction; actual uploaded-object ownership verification; independent return and
payment approval; claims/stays preventing enforcement and payouts; integer cents,
insufficient-fund checks, receipt replay protection, final reconciliation; immutable
closed cases. External payments and court delivery are recorded using references;
the application does not send payments or file with the court.

Checks completed locally:

- Existing complete source verification suite.
- `tests/civil-california-domain.test.mjs`: eleven paths from reviewed intake to
  independently reviewed court return and closure; rejected edits leave inputs
